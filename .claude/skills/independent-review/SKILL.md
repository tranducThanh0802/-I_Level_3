# independent-review

**Phòng:** Chất lượng  ·  **Checkpoint CEO (A4):** Reviewer PHẢI khác author. Verdict do bằng chứng, không do đồng thuận.

## Các bước
1. Mở nguồn chân lý + code + acceptance + ảnh; duyệt TỪNG tiêu chí.
2. Mặc định hoài nghi: nêu CỤ THỂ chỗ lệch (dòng nguồn vs dòng code).
3. Trả verdict PASS/FAIL + danh sách vấn đề xếp theo mức.

- Báo cáo review + verdict; nếu FAIL → quay lại implement.
